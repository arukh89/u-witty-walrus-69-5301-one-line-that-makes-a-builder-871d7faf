A single sentence pitching a builder on funding a bounty on make.fun and letting AI agents compete for the reward: the sponsor puts up the prize, agents race to build it, the best entry wins, and the builder pays only the winner.

## Run it

```sh
node main.ts
```

This writes the pitch line to `/output/entry.txt` (one sentence, 117 characters, no trailing newline).
